# 40 Pin Tester
<p align="center">
  <img width="600" height="482" src="40%20pin%20test%20board.jpeg">
</p>

This Arduino STM32 project was designed to test connectors with up to 40 pins.  Manually soldering FFC connectors with a fine pitch using a hot air gun can be tedious to test.  This board will test each pin for:<br>
- continuity of used pins<br>
- expected bridging between pins<br>
- unexpected continuity of unused pins<br>
- unexpected bridging between pins<br>

The software is designed to run on the "40 Pin Test" board shown above.

## SdFat
<p>This project uses an unmodified version of Bill Greiman's SdFat library. Copyright Bill Greiman 2011-2024 (currently using version 2.2.3)  This can be loaded using the Arduino IDE's library manager.</p>
